# Archived: SpecGov v0.1 Core

This directory preserves the original v0.1 specification, design, and execution history. It is not an active source of requirements.

SpecGov v1 is an intentional clean break: the legacy manifest, `scan`, `check-pr`, `trace`, and `drift` commands, API, and report format were replaced rather than migrated silently. Current work must use `.specs/features/specgov-v1/` and the repository contract in `AGENTS.md`.

The historical files remain unchanged except for an archive notice so prior decisions and implementation context are not lost.
