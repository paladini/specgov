# Support

## Questions and usage help

Before opening an issue, check the [README](README.md), the [v1 upgrade notice](docs/upgrade-v1.md), and existing issues.

Use a [question issue](https://github.com/paladini/specgov/issues/new?template=question.yml) for reproducible questions about configuration, framework discovery, CLI output, the programmatic API, or the GitHub Action. Include the SpecGov and Node.js versions, operating system, command, sanitized configuration, and relevant output.

Support is provided by the community on a best-effort basis. There is no guaranteed response time.

## Bugs and feature proposals

Use the matching issue form for bug reports, framework adapter proposals, or policy and feature requests. Please do not use issues for general AI-authorship detection requests: SpecGov governs declared development artifacts and does not infer who or what authored them.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting channel when available.
